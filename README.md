# Stumble

A speaking-first French practice app. You talk your way through real scenes with an AI character; every moment you freeze, fall back to English, or get corrected is captured in the sentence where it happened and becomes a spaced-repetition card. Progress is your deck shrinking.

Built for the Nerdy AI Hackathon (Prompt 02, language learning).

- `frontend/` — Next.js (App Router), mobile-first PWA
- `backend/` — FastAPI, MongoDB, FSRS scheduling, voice pipeline

Plan and design docs live at the repo root. Real README lands on day 6.
